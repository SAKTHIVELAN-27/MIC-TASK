1. Executive Summary & Project Description

EventSync is a production-grade event management and QR-based check-in platform engineered to solve high-concurrency event registration and entrance verification challenges. It guarantees zero over-registrations using atomic PostgreSQL transactions, generates high-contrast QR passes for instant optical scanning, provides an offline-first camera scanner, and delivers real-time attendance analytics powered by Google Gemini AI.

2. Core Features Built

🎟️ Event Management & Capacity Control

Atomic PostgreSQL transactions with Serializable isolation guarantee strict capacity limits without race conditions under concurrent load.

📱 High-Contrast QR Passes

Cryptographically unique 32-character tokens generated into standard black-on-white high-contrast QR pass images for instant camera scanning.

📷 Camera Scanner & Offline Sync

Hardware-accelerated camera scanner with native BarcodeDetector support, dynamic viewfinder scaling, local offline scan queuing, and automatic background sync.

⚡ Check-In Verification Portal

Public landing portal (/check-in/[token]) enabling 1-click arrival confirmation, verification badges, timestamp records, and scanner station selection.

📊 Real-Time Analytics & CSV Export

Interactive attendance trend charts, peak check-in time calculations, no-show rate metrics, and 1-click CSV data exports.

🤖 Natural-Language AI Insights

Integrated Google Gemini 1.5 Flash to process event stats and answer natural-language organizer questions grounded strictly in database facts.

  • RSC Serialization Fix: Replaced Lucide icon function props with serializable string names in components/dashboard/stat-card.tsx.
